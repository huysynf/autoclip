# 🎤 Whisper priority subtitle generation strategy

## 📋 Overview

Based on user suggestions, we have redesigned the subtitle generation strategy and prioritize using the Whisper model to generate subtitles by ourselves, rather than relying on subtitles from Bilibili/YouTube platform. This change results in a better user experience and more consistent subtitle quality.

## 🔄 New subtitle generation process

### 1. Priority strategy

```
用户上传字幕文件 → Whisper生成字幕 → 平台字幕（备用）
```

**Detailed process:**
1. **User provided subtitles**: If the user uploads an SRT file, use it directly
2. **Whisper generation**: If there are no user subtitles, Whisper generation will be used first.
3. **Platform subtitle backup**: If Whisper fails, try to download platform subtitles only

### 2. Intelligent model selection

Automatically select the appropriate Whisper model based on video content type:

| Content type | Model | Features | Applicable scenarios |
|----------|------|------|----------|
| Business/Knowledge | `small` | High accuracy | Tutorials, teaching, popular science videos |
| Speeches/lectures | `medium` | High precision | Speeches, lectures, sharing sessions |
| entertainment content | `base` | Balanced performance | Entertainment, games, lifestyle videos |
| default | `base` | Universal | Other types of videos |

### 3. Language detection strategy

- **AUTO-DETECTION**: used by default`auto`Perform language detection
- **Chinese content**: Business, knowledge, and speech content are designated as`zh`
- **Multi-language support**: Supports 15 languages, including Chinese, English, Japanese, etc.

## 🛠️ Troubleshooting

### FAQ

1. **Whisper is not installed**
   ```bash
   pip install openai-whisper
   ```

2. **FFmpeg is not installed**
   ```bash
   # 检查FFmpeg
   ffmpeg -version
   ```

3. **Model download failed**
   ```bash
   # 手动下载模型
   whisper --model base --help
   ```

4. **Insufficient memory**
- Use smaller models (tiny/base)
- Increase system memory
- Process long videos in batches

### Performance optimization

1. **Model Selection**
- Short video: use`tiny`or`base`
- Long video: use`base`or`small`
- IMPORTANT: USE`medium`or`large`

2. **Language specification**
- Known languages: directly specify the language code
- Unknown language: use`auto`Automatic detection

3. **Batch Processing**
- Multiple videos can be processed in parallel
- Process tasks using queue management
